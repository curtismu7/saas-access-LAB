# saas-access-LAB

Demo-tier standalone app: Ping SaaS Access Management release claims (deck slides 35 and 51, release 2026-11-02): just-in-time, time-bound access to GitHub, GitLab, Salesforce, Snowflake, Databricks and Google Workspace, with approval chains, self-approval blocked, a reaper that removes access on expiry, receipts, reference counting and nightly drift detection, the same for humans and agents. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7250). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app; scripts). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7250 docker compose up --build -d`. Node 26 only.
- Modes: **Mock** (default) = tables (`server/src/mockTable.json`, generated by `npm run mock-table` from six scripted scenarios run through the engine; a doctor check and a test fail on drift; read-only, every write is 409). **Live** = the real engine on the visitor's own requests. Both loopback-only, zero outbound (netguard + a test).
- Core: `engine.js` (the state machine: requests, decisions, grants, receipts hash chain, reaper, lab clock, drift, policies, notifications; one Engine per workspace and vertical, deterministic, no I/O), `catalog.js` (six platforms, 13 resources, auth METHOD names, illustrative call shapes), `policies.js` (editable policy fields, strict validation), `actions.js` (the one dispatch used by the API, the scenarios and the tests), `scenarios.js` (+ Mock table builder), `credentials.js` + `mask.js` (credential masking), `service.js`, `app.js`. Web: `useLab` hook (Mock and Live give one state shape, stale answers dropped), seven tabs.
- Rules that bite: the lab holds no credential for any platform (auth method NAMES only); a credential the visitor types is masked on the way in (`cleanFree`, `server/src/credentials.js`: a thin adapter over the shared masker in `server/src/shared/`, shared-masker 1.4.0 commit 9bc664a, copied unchanged, never edited here: fix it upstream and copy again; plain mark `[masked]`; exceptions the lab writes itself live in `maskConfig.js`) and again on every response, keys included (`maskDeep`, `mask.js`), the hop echo shows only known field names (`service.js` KNOWN_KEYS) and shaped path ids (`app.js` ID_SHAPE) and the mark for the rest, nothing is ever cut (over a limit = refused whole: `bounds.js` 413, reason 300 and comment 200 = 400), and `echo.test.js`, `sweep.test.js`, `corpus.test.js` and `sweep-http.test.js` type every shape (the shared corpora) into every field, key, path, query and header of every endpoint; a missing static file (and /assets, /assets/: the shell is for `isPageAddress` paths only) is a JSON 404, a wrong method a 405 with Allow (one `ROUTES` table in `app.js`), a charset other than utf-8 a 415, a credential-looking workspace id a 400 bad_workspace before a slot exists (the page retries once); unknown body keys are refused without naming them; every user value used as an object key is type-checked (`Object.hasOwn`); every grant carries an expiry (a request with a missing, string, negative, zero, fractional or oversized duration is refused, and `makeGrant` refuses too); the clock only moves forward; self-approval is not a policy field and is always refused; audit data can never overwrite an entry's kind (a real bug the tests caught); the six platforms, the call shapes, the receipt chain and the nightly time are lab-invented and tagged; the gateway app is always "P1 Privilege Agent App"; ports 7250-7299; UI: shared `web/src/styles/standalone-ui.css` vendored byte-for-byte, app CSS tokens only (`bash ~/Development/AI-DEMO-Standalone/scripts/check-css.sh .`).
- Field names (Sync, Hitl, ApproverNotifications, RetiredAt, WorkspaceID, the approval Spec and Status fields) come from the console swagger of 2026-10-31, schema only. They belong to other objects (agent approvals, accounts, integrations): reusing them here is a lab reading, tagged. Everything else is lab-invented and tagged so.
- Settings: one shared file `~/Development/.env` (mode 600, `STANDALONE_ENV` overrides), parsed with `util.parseEnv` in `server/src/settings.js`; this lab takes only `SAL_LAB_MODE`, never a bare MODE.
- Run check-drift, check-css and conformance by hand. SE k8s build deferred (owner, 2026-10-31); no k8s manifests. Catalog id D104 (assigned 2026-10-31, owner delegated the choice; not yet recorded in the plan).
